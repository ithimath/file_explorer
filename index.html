A. Encapsulation (FileItem.java)

Encapsulation binds data and functions together into a single unit and controls access via private fields and public getter/setter methods with validation.

// FileItem.java
public abstract class FileItem {
    // 1. Private fields hide data from unauthorized outside tampering
    private String name;
    private String path;
    private String type;
    private long size;

    // 2. Controlled access via validated setters & getters
    public String getName() { return name; }

    public void setName(String name) {
        if (name == null || name.trim().isEmpty()) {
            throw new IllegalArgumentException("File name cannot be empty");
        }
        this.name = name.trim();
    }
}

B. Inheritance (FileDocument & FolderItem extend FileItem)

Inheritance allows child classes to reuse common attributes (name, path, size, lastModified) from the parent class while adding their own specialized properties.

// Parent Class: FileItem.java
public abstract class FileItem { ... }

// Child Class 1: FileDocument.java
public class FileDocument extends FileItem {
    private String extension; // Specific to documents
    private boolean textFile;
}

// Child Class 2: FolderItem.java
public class FolderItem extends FileItem {
    private int childCount;   // Specific to directories
}

C. Polymorphism (Polymorphic Method getItemType())

Polymorphism allows the same method call to produce different behaviors based on the runtime object type.

// In Parent FileItem.java
public abstract String getItemType();

// In Child 1 (FileDocument.java)
@Override
public String getItemType() {
    return "File";
}

// In Child 2 (FolderItem.java)
@Override
public String getItemType() {
    return "Folder";
}

// Usage in Service/Controller:
for (FileItem item : items) {
    // Calls the overridden method polymorphically at runtime!
    System.out.println(item.getName() + " -> " + item.getItemType());
}
